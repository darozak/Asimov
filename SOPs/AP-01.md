# Standard Operating Procedure: AP-01

**Title:** Concept Intake and Standardization  
**Purpose:** To systematically extract novel concepts and frameworks from AI conversational logs and format them into structured, trackable documents for The Asimov Project.

## 1. Triggering the Workflow
This SOP is activated when the user inputs the command: "Execute AP-01 on the preceding conversation."

## 2. Topic Identification & ID Generation
Upon activation, the AI will analyze the conversation to identify all distinct topics, frameworks, or theoretical threads. For **each** distinct topic identified, the AI will generate a unique identifier using the format `cYYYYNN`:
* `c` denotes a conceptual framework.
* `YYYY` represents the current calendar year.
* `NN` represents a sequential two-digit number assigned to the concept for the current year (e.g., c202601, c202602).
* If multiple topics are extracted from a single conversation, `NN` must increment sequentially for each topic.

## 3. Content Extraction & Completeness
For each identified topic, the AI will review the preceding conversation and extract the core theories discussed. It is critical that the AI includes the entire scope of the original concepts without omitting key theoretical details, ensuring the output is a complete, fully accurate, and defensible representation of the brainstorm. 

## 4. Document Structure
The AI will organize the extracted information by creating a separate summary block for each topic. Each block must contain the following required sections:

### Concept ID & Date: [Insert cYYYYNN and Current Date]
* **Concept Name:** [Insert formal name of the theory/framework]
* **Definition:** [Provide a concise, accurate definition of the concept]
* **Relevance to The Asimov Project:** [Explain exactly how this framework supports the overarching mission of positive human-AI co-evolution]
* **Action Items:** [List tangible next steps for integrating this concept into the project repository or website]
* **Proposed Author Contributions:** [Summarize the specific roles the human and the AI played in conceptualizing and drafting this entry]

***
*(Note to AI: Insert a horizontal rule `***` or `---` between each concept block if multiple topics are extracted).*

## 5. Output Formatting Constraints
The AI must output the final document strictly using standard Markdown formatting to ensure full compatibility with GitHub and optimal AI readability. Use appropriate Markdown elements (`#` for headers, `**` for bolding, `*` or `-` for unordered lists, etc.) so that the content renders correctly in any standard Markdown viewer. Do not default to standard word processor text formatting.
