# White Papers

Formal research white papers for the Asimov Project, maintained under
[SOP PB-01](../SOPs/Procedures/PB-01%20Researching%2C%20Drafting%2C%20Editing%2C%20and%20Publishing%20White%20Papers.md).

- Each paper is a single Markdown file named `<ID> <Title>.md`, where the ID is
  `WP-YYYY-NN` (year, then a two-digit sequence within that year).
- Papers move through the states **Draft → In Review → Published**, and later
  **Superseded** or **Withdrawn**. The current state is in each paper's metadata block.
- Publication requires the User's approval; board review is optional and recorded in
  the paper when it occurs.
- Propose new papers and changes through the
  [AD-01](../SOPs/Procedures/AD-01%20Posting%20and%20Responding%20to%20GitHub%20Issues.md)
  issue and branch workflow. Start from
  [PB-01-T1](../SOPs/Attachments/PB-01-T1%20White%20Paper%20Template.md).
